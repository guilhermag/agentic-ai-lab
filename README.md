# Agentic AI Lab

Este repositório reúne uma trilha prática de estudos sobre IA Generativa, LLMs, RAG, agentes, LangGraph, LLMOps e avaliação de sistemas agentic.

A proposta é construir uma formação própria, estruturada e orientada a portfólio, substituindo uma especialização formal por uma trilha de estudo com fontes públicas, documentação, microprojetos e um projeto final.

## Objetivo

Desenvolver competências práticas em:

- aplicações com LLMs;
- RAG;
- agentes com ferramentas;
- LangGraph;
- avaliação de agentes;
- LLMOps;
- governança e uso responsável de IA;
- documentação técnica e portfólio.

## Estrutura da trilha

A trilha está organizada em 24 semanas:

| Bloco | Semanas | Tema |
|---|---:|---|
| 1 | 1–2 | Preparação da trilha |
| 2 | 3–5 | AI Engineering e sistemas de IA |
| 3 | 6–8 | LLMs, Transformers e prompting |
| 4 | 9–11 | RAG |
| 5 | 12–14 | Agentes e workflows |
| 6 | 15–18 | LangGraph |
| 7 | 19–21 | LLMOps e API |
| 8 | 22–23 | Governança, avaliação e produto |
| 9 | 24 | Projeto final |

## Regra da trilha

Cada bloco deve gerar pelo menos:

- um entregável técnico;
- um entregável escrito;
- um registro de progresso;
- uma decisão documentada, quando aplicável.
